# 🏡 THEGCTC — Home Decor Store

A polished responsive storefront demo for **THEGCTC**, a home-decor concept focused on warm minimalism, natural textures, lighting, mirrors, wall art, textiles, storage and tabletop accents.

## What is included

- **62 curated products** across 8 home-decor categories
- Reference prices checked **October 1, 2026**
- Live product photography pulled from the linked retailer product pages
- Product source links for IKEA, Target, At Home, Walmart, Wayfair and Nordstrom
- Search, category filters, retailer filter and price/name sorting
- Responsive desktop/mobile layout
- Demo shopping bag stored in the browser with `localStorage`
- Design advisory section with placeholder phone/email
- Local THEGCTC logo, favicon and hero artwork

## Run locally

Open `index.html` in a modern browser. For the live retailer product photos, an internet connection is required.

## Important before launch

This is a **demo storefront**. Prices and availability can change after the check date. Confirm all prices, inventory and permission to reuse third-party product photography before a commercial launch. Replace the placeholder advisory number and email with the store's official contact information.

## Files

- `index.html` — storefront markup
- `styles.css` — responsive visual design
- `app.js` — catalog, filtering, retailer links and cart demo
- `assets/logo.png` — THEGCTC logo
- `assets/hero.webp` — hero image
- `assets/product-placeholder.svg` — offline/image-error fallback
